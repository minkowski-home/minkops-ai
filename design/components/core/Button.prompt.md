The action control — use for every clickable action, in the console and on the marketing site alike.

```jsx
<Button variant="primary" size="lg" iconRight={<Icon name="chevronRight" size={16} />}>Request access</Button>
<Button variant="secondary">Acknowledge</Button>
<Button variant="ghost" size="sm">Back</Button>
```

One `primary` per view. `inverse` is for dark bands only. `danger` is a bordered white button with alert-red text, never a red fill. No scale or lift on hover — colour only.
