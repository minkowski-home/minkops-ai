Presents one agent on the marketing site's roster grid.

```jsx
<AgentTile name="Imel" tool="Email handler" domain="Generic" glyph="email" status="Live" />
```

Agent names are set in Readex Pro; the role line is plain text. Use the matching agent glyph — never a generic robot icon. Be truthful in `status`: only Imel and Kall are shipped today.
